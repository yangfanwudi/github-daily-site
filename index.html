功能特性Features

从检索到推送，一条命令全搞定From search to push, one command does it all

九个环节全部内置在一个 main.py 里（Config / GitHubClient / RepoFilter / Scorer / ReadmeSummarizer / Translator / ReportRenderer / Notifier / Pipeline），装好依赖即可运行。 All nine stages live inside a single main.py (Config / GitHubClient / RepoFilter / Scorer / ReadmeSummarizer / Translator / ReportRenderer / Notifier / Pipeline) — install the dependencies and you are ready to go.

多维度检索Multi-dimensional search

调用 GitHub Search API，topic:{t} + created:>{N天前} + language:{lang} 多组合逐个查询、合并去重，只盯最近 N 天新冒出来的仓库。Queries the GitHub Search API with topic:{t} + created:>{N-days-ago} + language:{lang} combinations, merged and deduplicated — only repos created within the last N days.

Token 池与限流容错Token pool & rate-limit resilience

多 PAT 自动轮换，实时监控 x-ratelimit-remaining；全部耗尽按 x-ratelimit-reset 等待（封顶 120 秒）；网络异常 / 5xx 指数退避重试，超时 connect 10s / read 30s。Rotates multiple PATs automatically while watching x-ratelimit-remaining; when exhausted it waits per x-ratelimit-reset (capped at 120 s). Network errors and 5xx get exponential-backoff retries; timeouts are 10 s connect / 30 s read.

硬性质量过滤Hard quality filters

剔除 fork 仓库、Star 低于 min_stars、无描述、README 拉取失败或为空的条目，全程打印各阶段过滤统计。Drops forks, repos below min_stars, entries without a description, and repos whose README fetch failed or came back empty — with per-stage filter stats printed along the way.

可配权重热度评分Weighted trending score

日均增星 + 对数压缩的 Star / Fork 体量三项加权求和，权重 w1/w2/w3 全部可在配置里调整，按分数排序取 Top N。Combines stars-per-day with log-scaled star and fork volume; the three weights w1/w2/w3 are fully configurable, and the list is ranked by score to keep the Top N.

LLM 摘要 + 规则兜底LLM summaries with rule fallback

线程池并发拉取 README（raw 优先、Base64 回退，截前 2000 字符），LLM 提炼【核心功能】【技术栈】【适用场景】与一句话亮点；未配置 LLM 时本地规则生成同等结构，任何字段不会留空。Fetches READMEs concurrently (raw first, Base64 fallback, first 2,000 chars) and distills core features, tech stack, use cases and a one-line highlight via any OpenAI-compatible LLM. Without an LLM key, local rules produce the same structure — no field is ever left empty.

免费中文翻译Free Chinese translation

MyMemory 免费引擎（无需 API Key，匿名额度约 5000 字符/天），翻译结果缓存到本地，重复内容零消耗；超额度内容次日自动补翻，失败只跳过该条，绝不中断报告。The MyMemory engine works without an API key (roughly 5,000 chars/day anonymously). Results are cached locally so repeated content costs nothing; anything over the daily budget is translated the next day, and a failed item is simply skipped — report generation never breaks.

飞书 / 钉钉推送Feishu / DingTalk push

热度评分公式The trending score

更看重「刚创建就快速涨星」，同时保留体量参考： It favors repos that gain stars fast right after creation, while keeping volume in play:

score
score = w1 × (stars / days_since_created) # 日均增星，衡量「近期增速」
      + w2 × log10(1 + stars) # 绝对热度（对数压缩，避免头部碾压）
      + w3 × log10(1 + forks) # 社区参与度 score = w1 × (stars / days_since_created) # stars per day since creation (growth speed)
      + w2 × log10(1 + stars) # absolute popularity, log-scaled
      + w3 × log10(1 + forks) # community engagement

仓库年龄下限 1.0 天，避免除零与超新仓库失真；想更偏体量就调大 w2 / w3，更偏增速就调大 w1。 Repo age is clamped to a 1.0-day minimum to avoid division blow-ups; raise w2 / w3 to favor volume, raise w1 to favor growth speed.

常见问题FAQ

你可能想问You might be wondering

报「GitHub API 限流警告」或搜索结果为空？Seeing rate-limit warnings or empty results?
匿名访问配额为 60 次/小时（Search 接口 10 次/分钟）。在 tokens 里填 1~2 个无权限要求的 classic PAT（github.com/settings/tokens），配额提升至 5000 次/小时；工具会自动轮换，全部耗尽时按 x-ratelimit-reset 等待（封顶 120 秒）。 The anonymous quota is 60 requests/hour (10/minute for the Search API). Add one or two classic PATs — no scopes needed — to tokens to raise it to 5,000/hour. The tool rotates tokens automatically and, when all are exhausted, waits per x-ratelimit-reset (capped at 120 seconds).
代理环境如何配置？Behind a proxy?
无需配置——工具默认自动使用系统代理（环境变量或 Windows Internet 选项）；代理软件没运行 / 端口失效时，会自动切换为直连模式继续运行。特殊场景可显式设置 HTTP_PROXY / HTTPS_PROXY 环境变量。 Nothing to configure — the system proxy (environment variables or Windows Internet options) is picked up automatically, and if the proxy is down or its port is stale the tool falls back to a direct connection and keeps going. For special cases you can set HTTP_PROXY / HTTPS_PROXY explicitly.
Windows 控制台中文乱码？Garbled Chinese in the Windows console?
本工具所有文件均为 UTF-8，在 Windows Terminal / Git Bash 下正常显示。若在旧版 cmd 中乱码，先执行 chcp 65001；由计划任务运行的 run_daily.bat 已强制 UTF-8，不受此影响。 Everything is UTF-8 and renders fine in Windows Terminal / Git Bash. In a legacy cmd console, run chcp 65001 first; the scheduled run_daily.bat already forces UTF-8, so it is unaffected.
为什么有些仓库被过滤掉了？Why are some repos filtered out?
命中任一硬性条件即剔除：fork 仓库、Star 低于 min_stars、无描述、README 拉取失败或为空。运行结束的过滤统计表会展示各阶段剔除数量。 A repo is dropped if it hits any hard rule: it is a fork, its stars are below min_stars, it has no description, or its README fetch failed or came back empty. The filter-statistics table shows the count removed at every stage.
